# DC-NBS-Songs

NBS音乐合集，主要供 Disc-Jockey 模组演奏。此模组已打包在 DC整合包 **可选MOD** 中

## 安装音乐包

1. 进入音乐文件夹：`.minecraft\versions\【DreamCity】生存服XX.X\config\disc_jockey\songs`

2. 打开终端（cmd或者Powershell）

3. 执行命令拉取音乐包到本地：
   ```shell
   git clone https://github.com/DreamCity-DC/DC-NBS-Songs .
   ```

   **最后一个点别漏了**

4. 启动Minecraft，开始演奏！

## 更新音乐包

1. 进入音乐文件夹：`.minecraft\versions\【DreamCity】生存服XX.X\config\disc_jockey\songs`

2. 打开终端（cmd或者Powershell）

3. 执行命令更新音乐包：

   ```shell
   git pull
   ```
